# Gold Goblin website

The website for [Gold Goblin](https://tainamalave.github.io/gold-goblin-site/), a Discord bot that tracks the World of Warcraft Token price and alerts your server or DMs you when it hits your target.

It's plain HTML and CSS with no build step, published with GitHub Pages from the `main` branch.

| File | Page |
| --- | --- |
| `index.html` | The main page: what the bot does, its features, commands and the "Add to Discord" button |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Service |
| `assets/styles.css` | Shared styles for all three pages |
| `assets/gold-goblin-icon.PNG` | The original Gold Goblin icon |
| `assets/icon-256.png`, `icon-512.png`, `favicon-64.png` | Smaller copies of the icon used by the pages |

To preview locally, open `index.html` in a browser. To publish a change, push to `main`. GitHub Pages updates within a minute or two.
